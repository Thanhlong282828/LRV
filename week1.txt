# D1 — Product Analyzer

## Mục tiêu

Ôn lại:

`Array → foreach → if/else → sort → search → calculation`

Mục tiêu không phải học syntax mới mà kiểm tra:

> **Nhìn requirement → tự nghĩ được code cần làm gì hay chưa?**

### Coding Task

Tạo 10 sản phẩm.

Mỗi sản phẩm có:

```
id
name
category
price
stock
```

Chương trình phải thực hiện được:

1. List toàn bộ products.
2. Filter products có `price > 100000`.
3. Tìm product đắt nhất.
4. Sort price từ cao → thấp.
5. Tính total stock.
6. Tính inventory value = `Σ price × stock`.
7. Search product theo name.

### Quy trình làm

**Bước 1 — 15 phút:** đọc requirement và viết bằng comment mình định làm gì.

**Bước 2 — 60 phút:** tự code, chưa dùng ChatGPT.

**Bước 3 — Nếu bí >15 phút:** sử dụng Coding Coach Prompt.

**Bước 4 — 30 phút:** tự thay data để test.

**Bước 5 — 15 phút:** cleanup code.
